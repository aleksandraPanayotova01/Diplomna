# Diplomna
A web application of a university system that includes administrator, teacher and student profile types. 

To start in the Command Prompt (cmd) write:
cd fullFolderPath (Example: C:\Users\Alexandra\Diplomna)
npm run dev

For future improvement:
1. The start panel should be updated- it should have 1 login form that checks the username and assigns the appropriate user type
2. The personal identification number (egn) should not be hashed as the password is. It should be accessible if it is requested during registration.
3. The names of the subjects should not be able to be updated. Once added the study program should stay as is.
4. The foreign students studing in Bulgaria should have the option to add other form of identification different from egn.
